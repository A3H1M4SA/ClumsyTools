ICON0.PNG - Application Icon
=============================

Required: 320x176 pixels PNG image
Location: pkgfiles/ICON0.PNG

This icon will appear in the PS3 XMB (XrossMediaBar) menu.

You can:
1. Create your own 320x176 PNG image
2. Use an existing PS3 app icon as template
3. Download a placeholder from PS3 homebrew resources

Once you have your icon, place it here as:
pkgfiles/ICON0.PNG

The build process will automatically include it in the PKG file.
